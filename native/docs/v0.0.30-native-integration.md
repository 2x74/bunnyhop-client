# Website v0.0.30 integration

The native client vendors the website's v0.0.30 hotfix, `hotfix/0030-wasm` commit
`6a37d059f59291a25ac3bbfefd5d1aa6ad5f45f4`. New runs use physics 20 and timer rules 2; replay playback retains physics
1–19. The unpatched verifier rebuilt with Rust 1.99.1 is 1,474,290 bytes, SHA-256
`2b4e6a763c750cd674dd92288d96d502a24d1294723ceff051f8f8ec906e1212`.

- Physics v20 is bhoptimer's autohop: with jump held, walking and water level below 2, a command keeps its jump and
  only the old jump latch is cleared. Unducking or a teleport onto a floor jumps on that command without a friction
  tick. Native passes held jump and wheel pulses to the core unchanged; the core applies the rule.
- `!showtriggers` draws scripted triggers that have no map outputs, such as bhop_cooksassistant's ingredients and
  gates, from the core's overlay.
- Map mechanics, per-map maximum velocity and the Areaportal/Profane/Playboy fixes come from the shared core.
  Native input consumes its teleport angles. The speed graph scales to the observed peak.
- `!practice off` ends noclip, turns mode off, clears this map's practice spawns across tracks, and restarts.
  Ranked custom starts, other maps' starts and checkpoint saves remain. Explicit `on` and `off` are idempotent;
  bare commands, binds and the menu toggle. The existing toast reports cleared spawns.
- Practice saves retain the shared core snapshot, including template instances, script scope, queues and deadlines.
  Restart resets that world state while retaining checkpoint handles for a later restore.
- HUD presets keep the strafe trainer switch, including the native layout editor's presets and reset. The HUD
  reads the website's layout switch; trainer presets enable it.
- Segmented stays out of native style selection and cannot upload. Shared snapshots are available, but native
  still needs the checkpoint timer/path restore, stitched replay rebuild and BHSG load trailer.
- Online map preparation and texture decoding run on a cancellable worker. Renderer uploads and normal maps are
  staged across frames; cutout pixel processing and shared model file reads run on workers. The BSP limit is
  768 MiB, with the core's decoded-lump and pak limits intact; optional decoded texture preparation is capped at
  512 MiB. `bunnyhop-native-load-benchmark` uses windowless CGL on macOS to measure this path.

Brush presentation follows the website's model slots: the last instance transform and first visibility row for
that model. Generic simultaneous instances and spawned VPhysics props remain unsupported on both clients.
Native retains its existing eleven bundled offline music tracks; the vendored web catalogue contains 22.
No menu layout or styling changes are part of this integration.

## Re-sync at freeze

From `native/`, run this single command after obtaining the website team's final expected digest and byte count:

```sh
bun tools/sync-upstream.ts --upstream /Users/hunter/src/bunnyhop \
  --commit 6a37d059f59291a25ac3bbfefd5d1aa6ad5f45f4 \
  --wasm-sha256 2b4e6a763c750cd674dd92288d96d502a24d1294723ceff051f8f8ec906e1212 \
  --wasm-bytes 1474290 --build-wasm
```

The tool reads Git objects, applies native patches, refreshes both verifier pins and rebuilds the unpatched WASM.
It rejects local vendor edits, patch conflicts and a mismatched verifier. If the website changes its verifier,
use its newly reviewed digest/size and repeat the checks below. Never edit vendored output to resolve a conflict.

## Offline checks

Keep SHA-verified original BSPs and their release `.zones.json` files outside Git. Set `CONTENT_CACHE_DIR` to the
matching content cache, including its `physics/<map>.txt` manifests. Core tests also need `bhop_eazy` and
`bhop_ancient`. Run from `native/`:

```sh
bun run build
bun run check
SDL_VIDEO_DRIVER=dummy SDL_AUDIO_DRIVER=dummy ctest --test-dir apps/native/build --output-on-failure \
  -E 'native_paint_render|native_menu_focus|native_window_sdl'
cargo test --locked -p bunnyhop-core
cargo test --locked -p bunnyhop-core --test timing_path -- --ignored
cargo test --locked -p bunnyhop-native-bridge
BH_V19_MAPS=/tmp/bh-062-v0030/maps cargo test --release --locked -p bunnyhop-native-bridge v19_ \
  -- --ignored --nocapture --test-threads=1
bun test ./apps/native/packaging
bun apps/native/tools/parity-gate.ts --output target/v20-release-gate
bun apps/native/tools/v19-probes.ts --maps /tmp/bh-062-v0030/maps
bun apps/native/tools/v20-probes.ts --map /tmp/bh-062-v0030/maps/bhop_dom.bsp
bun apps/native/tools/areaportal-parity.ts --map /tmp/bh-062-v0030/maps/bhop_areaportal_v1.bsp
```

Build and run the windowless macOS load profiler with full loose content:

```sh
cmake --build apps/native/build --target bunnyhop-native-load-benchmark
apps/native/build/bunnyhop-native-load-benchmark /path/to/map.bsp /path/to/loose-content
```

`v20-probes.ts` compares a crouch-cancel landing and a teleport onto bhop_dom's floor at physics 19 and 20, tick for
tick. For PonyTrap's run, `apps/native/tools/parity.ts --map bhop_dom.bsp --replay UJ2mcyOKq1LxloTN.bhr --physics 20
--contrast-physics 19` first diverges at tick 1096.

The replay round trips are unfinished offline fixtures, not full-course or accepted-score proofs. Run
`apps/native/tools/parity.ts` on each original BSP for the general 2,000-tick comparison. The website's pinned
`tools/verify/map-mechanics-parity.ts`, `tools/maps-mech3/parity.ts` and `tools/verify/momentary-parity.ts` provide
positive mechanic and wheel probes; run exported copies with the same WASM and map/content fixtures.
The native test also compares complete snapshot state and its future trajectory after practice restore.
Stock collision files absent from the website's source bundles remain missing on both sides.

Regenerate input/HUD vectors after every sync:

```sh
bun tools/timed-input/generate-vectors.ts --web apps/web/src/timed-input.ts
bun tools/movement-hud/generate-vectors.ts --web . --vendored
bun tools/run-timing/generate-vectors.ts
bun tools/run-diagnostics/generate-vectors.ts
```

The build writes `target/native-menu/native-manifest.json` using the packager's exact identity function and
Mach-O hash convention. Each packaged target gets its own real build identity. Server admission is a separate
release operation; its array entries have `build`, `wasm`, `physics`, `rules` and a finite ISO UTC `until`.
