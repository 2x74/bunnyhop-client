Linux package baseline: Ubuntu 24.04 x86_64 (or the matching distribution/architecture used to build it).
Native SDL/OpenGL gameplay, WebKitGTK 4.1 menus/account. glibc, GPU/display drivers and the system
WebKitGTK/GTK runtime are deliberately provided by the operating system and receive its security updates.

Ubuntu/Debian runtime installation (review and run yourself):
  sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0t64 libgl1 libegl1 libx11-6 libxext6 libwayland-client0

SDL3 and non-system HTTP/compression dependencies are included when the build links them dynamically.
RUNTIME.txt lists the exact linked libraries of this build. For another distribution, build/package there.
